# Customer Management Practice Application
This is a simple **Spring Boot** application that demonstrates basic usage of **Spring Data JPA**, data sorting, and fake data generation using **Java Faker**, with a persistent **PostgreSQL** database using Docker Compose. It creates and manages a list of customers, sorts them, and prints results on startup.

## Technologies
- Java 11+
- Spring Boot
- Spring Data JPA
- Java Faker
- PostgreSQL
- Docker & Docker Compose

## Getting Started
### Prerequisites
